# Applied Bioinformatics & Structural Analysis Internship

This repository contains my practical work for the BioCode Innovators Bioinformatics & Molecular Docking Internship.

## Assignments
- `Data_Retrieval/` — NCBI, PDB and UniProt data-retrieval exercises.
- `Sequence_Analysis/` — BLAST and sequence-analysis work.
- `Structure_Refinement_and_Validation/` — structure validation/refinement work.
- `projects/` — evolutionary projects assigned during the internship.

## Evolutionary Projects
1. **Evolutionary Conservation of the Human TP53 Gene** — TP53 / NP_000537.3.
2. **Comparative Evolutionary Analysis of the Human Insulin Gene** — INS / NP_000198.1.
3. **Phylogenetic Analysis of the Hemoglobin Beta (HBB) Gene** — HBB / NP_000509.1.

Workflow used for the evolutionary projects: NCBI → BLAST → sequence selection → MEGA multiple sequence alignment → phylogenetic tree → iTOL → project report.

Human reference records: TP53 is represented by NM_000546.6 → NP_000537.3; INS by NM_000207.3 → NP_000198.1; and HBB by NM_000518.5 → NP_000509.1.
