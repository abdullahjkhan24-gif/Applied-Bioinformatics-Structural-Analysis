# Project 1 — Evolutionary Conservation of the Human TP53 Gene

## Objective
Analyze conservation of the human TP53 tumor-suppressor protein across mammalian homologs and construct a phylogenetic tree.

## Reference
Human TP53: **NM_000546.6 → NP_000537.3** (NCBI RefSeq).

## Workflow
NCBI sequence retrieval → BLASTx → homolog selection → MEGA 12 ClustalW MSA → Neighbor-Joining phylogenetic tree → iTOL visualization → report.

## Folder structure
01_NCBI_Sequence_Retrieval · 02_BLASTx · 03_Sequence_Selection · 04_MEGA12_MSA · 05_Phylogenetic_Tree · 06_iTOL · 07_Project_Report

The raw sequence, BLAST output, selected homologs, alignment, tree, screenshots and final interpretation should be placed in their corresponding folders.
