# Project 2 — Comparative Evolutionary Analysis of the Human Insulin Gene

## Objective
Investigate evolutionary relationships of the human insulin (INS) gene/protein by comparing homologous sequences from diverse vertebrates.

## Human reference
NCBI RefSeq: **NM_000207.3 → NP_000198.1**, insulin preproprotein.

## Workflow
NCBI sequence retrieval → BLAST search → homolog selection → MEGA 12 multiple sequence alignment → phylogenetic tree → iTOL visualization → report.

## Required folders
01_Project_Guidelines · 02_NCBI_Sequence · 03_BLAST_Analysis · 04_Multiple_Sequence_Alignment · 05_Phylogenetic_Tree · 06_iTOL_Visualization · 07_Project_Report
