# Project 3 — Phylogenetic Analysis of the Hemoglobin Beta (HBB) Gene

## Objective
Explore sequence conservation and evolutionary history of HBB by analyzing homologous hemoglobin-beta sequences from mammals.

## Human reference
NCBI RefSeq: **NM_000518.5 → NP_000509.1**, hemoglobin subunit beta.

## Workflow
NCBI sequence retrieval → BLAST search → homolog selection → MEGA 12 multiple sequence alignment → Neighbor-Joining tree → iTOL visualization → report.

## Required folders
01_Project_Guidelines · 02_NCBI_Sequence · 03_BLASTp_Analysis · 04_Multiple_Sequence_Alignment · 05_Phylogenetic_Tree · 06_iTOL_Visualization · 07_Project_Report
