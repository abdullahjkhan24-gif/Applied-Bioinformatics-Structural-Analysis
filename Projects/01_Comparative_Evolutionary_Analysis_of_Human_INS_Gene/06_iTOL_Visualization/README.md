# iTOL visualization

`INS_NJ_tree.nwk` is an iTOL-ready Newick tree generated from the computed Neighbor-Joining analysis.

## Suggested iTOL setup

- Upload `INS_NJ_tree.nwk`.
- Use a rectangular or circular tree.
- Display leaf labels using the species/accession identifiers.
- Keep branch lengths enabled.
- Add a simple taxonomy annotation separating mammals from the zebrafish and Xenopus comparison sequences.
